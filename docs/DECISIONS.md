# Decisions
- 2026-11-12 lead: cocos-cli install blocked by the session's auto-mode permission policy ("Code from External"). Everything not depending on it is built; Cocos layer typechecks against a hand-written `cc` shim (types/cc-shim.d.ts).
- 2026-11-12 lead: added a Canvas2D web preview (tools/preview) that renders the same core + atlas, used for e2e screenshots and bot autoplay while the Cocos build is unavailable. It is a debug tool, not the shipping client.
- 2026-11-12 art-ui: atlas.json frames may carry two additive fields: `slice: [l,t,r,b]` (9-slice insets, art px) and `advance` (font glyph pen advance). `font.json` repeats glyph advances per font (font5 lineHeight 10, font7 lineHeight 12; glyphs are white `w` with a 1px `k` outline, anchor (1,1) = cell top-left, so tint by multiply). build-atlas lint exemptions: 9-slice sprites and font glyphs skip the "fills its bounding box" check; the space glyph may be empty. A sprite module's declared `kind` wins over the manifest kind (lint + default anchor); differences are printed as warnings.
- 2026-11-12 game: UI laid out in a ~240px-wide UI pixel space scaled by an integer device-px factor; big-text mode scales text ×1.5 (may produce mixels).
- 2026-11-12 game: drawer cards show cost as icon + short text (e.g. `20w 10s`).
- 2026-11-12 game: light overlay snaps to tile light level → discrete alpha with 4px stair-step edges; flicker ±0.25 tile.
- 2026-11-12 game: run snapshot saved at dawn and at each new day.
- 2026-11-12 game: unverified without the real engine — Boot bootstrap in a real build, `art/atlas/texture` sub-asset path (ImageAsset fallback), uploadData row order, UI_2D camera, real draw calls/FPS.
- 2026-11-12 core: api.ts additive — Commands `hire` (tavern), `endless`, `skipTutorial`; Events `shrine`, `falseDawn`, `pulse` (Unlit), `teleport`, `heal`, `hired`, `enrage`; types `ShrineBuff`, `AllyId`, `AllyState` (barracks militia / Tobi's turret live in `state.allies`, not `enemies`), `ZoneState` (fire wall / sanctum in `state.zones`); GameState fields `allies, zones, boonSource, tavernOffer, buffs{shrine,falseDawnT,unlitPulseT,hearthLightMul}, endless, nightT, squadMax`. Tar trap uses `BuildingState.lit` = burning, spikes use `charges` (0 = retracted). Rift POIs carry `data.index` (= OmenEntry.rift).
- 2026-11-12 core: Game mutates `meta.tutorialDone = true` when the tutorial finishes or is skipped; the view persists meta. Meta helpers (unlock hero/blueprint, talents, ember) are exported from sim/Game.ts (implemented in sim/Meta.ts).
- 2026-11-12 core: the Hearth cannot be repaired or sold (its HP is the run's life; heal sources are the shrine, Rekindle boon and Hearth upgrades); Tobi/workshop/Living Fortress also skip it.
- 2026-11-12 core: selling during DUSK refunds 100% of everything invested; otherwise 60% (+10%/Thrift talent). Undo refunds 100% within the same build session (max 20 steps).
- 2026-11-12 core: brazier fuel is paid at the start of DUSK (nearest-to-Hearth first); braziers relight every DAY. Unlit pulse turns braziers off for 6 s (auto-relight), snuffers put them out until a hero stands next to them 2 s (Ilka instantly within 3).
- 2026-11-12 core: building placement is blocked by any resource node except stumps and bushes; small/medium rocks are walkable, trees/large rocks/ore/cages block movement.
- 2026-11-12 core: cages free a hero the player has unlocked but does not own yet (else any un-owned hero). Talent "Ready Horn" = 50/75/100% precharge; talents give +20 wood, +15 stone, +10% Hearth HP, +8 s day, +1 starting level, +10% refund, +1 chest choice per level.
- 2026-11-12 core: balance tuning (to pass §13.6): Mossback HP 1500→1000; The Unlit HP 4000→6500, speed 0.7→1.0, collision radius capped (bosses keep a large crush/render size); late-night wave HP ×(1 + 0.4·max(0, n−5)); enrage after 105 s (was 120) with ×1.5 speed and ×3 damage, and enraged spitters stop range-harassing and push for the Hearth (guarantees nights end < 150 s). Results: NoBuildBot loses by night 4 on 97% of seeds, BaselineBot survives night 5 on 87% and wins 0%, AutoplayBot wins ~70%.
- 2026-11-12 core: anti-stuck rules for path followers (re-centre on the current cell after 0.5 s without progress, ignore crowd separation while doing so, slip to the next waypoint after 3 s; units in a sealed pocket squeeze toward the Hearth); followers snagged for 1.5 s regroup on the leader.
